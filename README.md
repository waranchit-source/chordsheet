# ระบบเนื้อเพลงและคอร์ด (Lyrics & Chords)

ระบบแบ่งเป็น 2 ส่วน

| ส่วน | อยู่ที่ไหน | หน้าที่ |
|---|---|---|
| หน้าเว็บ (Frontend) | GitHub Pages: https://waranchit-source.github.io/chordsheet/ (ไฟล์ในโฟลเดอร์ `docs/`) | หน้าจอทั้งหมดที่ผู้ใช้เปิดใช้งาน |
| ระบบหลังบ้าน (Backend API) | Google Apps Script ที่ผูกกับ Google Sheet "Worship song" (ไฟล์ `.gs` ทั้งหมด) | อ่าน/เขียน Google Sheet สร้างไฟล์ PDF/Word ส่งให้ดาวน์โหลด (ไม่เก็บไฟล์ใน Drive) ตรวจสอบสิทธิ์ผู้ใช้ |

ข้อมูลทั้งหมดยังเก็บใน Google Sheet เหมือนเดิม หน้าเว็บบน GitHub เรียก Apps Script ผ่านลิงก์ Web app (ลงท้ายด้วย `/exec`)

## ย้ายระบบเดิมมาใช้ GitHub (ทำครั้งเดียว)

1. เปิด Google Sheet "Worship song" → **Extensions → Apps Script**
2. วางโค้ดใหม่ทับไฟล์เหล่านี้ทั้งไฟล์: `Code.gs`, `Config.gs`, `Auth.gs`, `Db.gs`, `Setup.gs`, `Songs.gs`, `Setlists.gs`, `Render.gs`
   (`Stats.gs`, `FontMetrics.gs`, `appsscript.json` ไม่มีการเปลี่ยนแปลง)
3. ลบไฟล์ HTML เดิม 4 ไฟล์ออกจาก Apps Script: `Index`, `Styles`, `Chords`, `App` (คลิกจุด 3 จุดข้างชื่อไฟล์ → Delete)
4. กด **Save project**
5. เลือกไฟล์ `Setup.gs` → ฟังก์ชัน `setup` → กด **Run** หนึ่งครั้ง ระบบจะเพิ่มคอลัมน์ `Status`, `ReviewedBy`, `ReviewedAt` ในชีต `Users` และสร้างชีต `Sessions` (ข้อมูลเดิมไม่หาย ผู้ใช้เดิมทุกคนยังเข้าระบบได้ตามปกติ)
6. กด **Deploy → Manage deployments** → เลือก deployment เดิม → ไอคอน **ดินสอ (Edit)** → Version: **New version** → **Deploy**
   ต้องเป็น Execute as: **Me** และ Who has access: **Anyone**
7. คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) ไปใส่ใน `docs/config.js` ที่ค่า `API_URL` แล้ว push ขึ้น GitHub
8. เปิด https://waranchit-source.github.io/chordsheet/

ลิงก์ `/exec` เดิมจะแสดงหน้าแจ้งให้กดไปที่ลิงก์ใหม่ (ตั้งค่าได้ที่ `FRONTEND_URL` ใน `Config.gs`)

## ติดตั้งใหม่ทั้งหมด (กรณีเริ่มจากศูนย์)

1. สร้าง Google Sheet ใหม่ → **Extensions → Apps Script**
2. สร้างไฟล์ Script ตามตารางด้านบน (เฉพาะไฟล์ `.gs`) แล้ววางโค้ด
3. เปิด `appsscript.json`: **Project Settings (ไอคอนเฟือง)** → ติ๊ก **Show "appsscript.json" manifest file in editor** → วางทับทั้งไฟล์
4. รันฟังก์ชัน `setup` → **Review permissions** → เลือกบัญชี → **Advanced** → **Go to (ชื่อโปรเจกต์) (unsafe)** → **Allow**
5. ดู **Execution log** จะเห็น Username `admin` และรหัสผ่านที่ระบบสุ่มให้ (จดไว้)
6. **Deploy → New deployment** → Web app → Execute as: **Me** → Who has access: **Anyone** → **Deploy**
7. นำ Web app URL ไปใส่ใน `docs/config.js` แล้ว push ขึ้น GitHub

ถ้าลืมรหัส admin หรือ admin ถูกล็อกเพราะกรอกผิด 5 ครั้ง: เลือกไฟล์ `Setup.gs` → ฟังก์ชัน `resetAdminPassword` → Run → ดูรหัสใหม่ใน Execution log แล้วเข้าสู่ระบบได้ทันที (ระบบปลดล็อกให้ ไม่ต้อง Deploy ใหม่) จากนั้นเปลี่ยนรหัสผ่านที่เมนู My account

หมายเหตุ: ช่อง `PasswordHash` ในชีต `Users` เป็นรหัสยาว 64 ตัวอักษรเสมอ เพราะระบบเก็บรหัสผ่านแบบเข้ารหัส (hash) เวลาเข้าสู่ระบบให้ใช้รหัสผ่านที่พิมพ์ตอนสมัคร

## อัปเดตโค้ดหลังแก้ไข

- **แก้ไฟล์ `.gs`**: วางโค้ดใน Apps Script → Save → **Deploy → Manage deployments → Edit → New version → Deploy** (URL เดิมใช้ต่อได้)
- **แก้ไฟล์ใน `docs/`**: push ขึ้น GitHub branch `main` แล้ว GitHub Pages จะอัปเดตเองภายใน 1 ถึง 2 นาที
  ควรเปลี่ยนเลข `?v=` ท้ายชื่อไฟล์ใน `docs/index.html` ทุกครั้ง เพื่อให้เบราว์เซอร์โหลดไฟล์ใหม่
- **แก้ `appsscript.json` แล้วมีสิทธิ์ (scope) ใหม่**: หลังวางโค้ดและ Save ให้เลือกไฟล์ `Setup.gs` → ฟังก์ชัน `setup` → **Run** หนึ่งครั้ง → **Review permissions** → เลือกบัญชี → **Advanced** → **Go to (ชื่อโปรเจกต์) (unsafe)** → **Allow** แล้วจึง Deploy เป็น New version (ถ้าไม่ทำ หน้าเว็บจะสร้างไฟล์ไม่ได้)
  ตั้งแต่ 2026-11-09 ระบบใช้สิทธิ์ `script.external_request` เพิ่ม เพื่อเรียกตัวแปลงไฟล์ของ Google Docs โดยตรง (หน้าขออนุญาตจะเขียนว่า "Connect to an external service")

## การลงทะเบียนและการอนุมัติ

1. ผู้ใช้ใหม่กด **Request access** (ขอสมัครใช้งาน) ในหน้าเข้าสู่ระบบ กรอก Username ชื่อที่แสดง และรหัสผ่าน
2. ผู้ดูแลระบบจะเห็นตัวเลขแจ้งเตือนที่เมนู **Users** → แท็บ **Requests** กด **Approve** แล้วเปิดสวิตช์สิทธิ์ที่ต้องการ (เริ่มต้นปิดทุกข้อ) จากนั้นกด **Approve** อีกครั้ง หรือกด **Reject**
3. ผู้ใช้เข้าสู่ระบบได้หลังจากได้รับการอนุมัติเท่านั้น (ถ้ายังรอ หรือถูกปฏิเสธ ระบบจะแจ้งข้อความให้ทราบ)
4. ผู้ที่ถูกปฏิเสธสามารถส่งคำขอใหม่ด้วย Username เดิมได้
5. ผู้ดูแลระบบยังเพิ่มผู้ใช้เองได้ที่ปุ่ม **Add user** (ผู้ใช้ที่ admin สร้างใช้งานได้ทันที สิทธิ์เริ่มต้นปิดทุกข้อเช่นกัน)

## จดจำการเข้าสู่ระบบ (Remember me)

- ติ๊ก **Remember me** ตอนเข้าสู่ระบบ: อยู่ในระบบต่อบนอุปกรณ์นั้น 30 วัน (นับใหม่ทุกครั้งที่ใช้งาน) และจำ Username ไว้ให้
- ไม่ติ๊ก: ออกจากระบบเมื่อปิดเบราว์เซอร์
- กด **Sign out** จะลบการจดจำของอุปกรณ์นั้นทันที
- ถ้า admin ปิดใช้งานผู้ใช้ เปลี่ยนรหัสผ่านให้ หรือปฏิเสธ การจดจำ 30 วันของผู้ใช้นั้นจะถูกลบ (หน้าที่เปิดค้างอยู่จะใช้งานต่อได้อีกไม่เกิน 6 ชั่วโมง เหมือนระบบเดิม)
- ระบบเก็บเฉพาะค่า hash ของ token ในชีต `Sessions` ไม่เก็บรหัสผ่าน

## สิทธิ์ผู้ใช้

ผู้ดูแลระบบเปิด/ปิดสิทธิ์ได้ทีละข้อ ที่เมนู **Users** → **All users** → ปุ่ม **Manage** (หรือตอนอนุมัติคำขอสมัคร)

| สวิตช์ | ทำอะไรได้ |
|---|---|
| ดูเพลง (View songs) | เปิดคลังเพลง ดูเนื้อเพลงและคอร์ด เปลี่ยนคีย์บนจอ |
| เพิ่มและแก้ไขเพลง (Add and edit songs) | เพิ่มเพลงใหม่ แก้ไขเพลงเดิม |
| ลบเพลง (Delete songs) | ลบเพลงออกจากคลังเพลง |
| จัดการหมวดหมู่ (Manage categories) | เพิ่ม เปลี่ยนชื่อ และลบหมวดหมู่เพลงที่หน้า Categories |
| สร้างชุดเพลง (Build setlists) | เลือกเพลง สร้างและดาวน์โหลดไฟล์ PDF/Word และมีชื่ออยู่ในรายชื่อผู้นำเพลง |
| ดูประวัติ (View history) | ดูชุดเพลงย้อนหลัง |
| ลบประวัติชุดเพลง (Delete setlists) | ลบชุดเพลงออกจากประวัติพร้อมสถิติของชุดนั้น |
| ดูสถิติ (View stats) | ดูว่าแต่ละเพลงถูกใช้บ่อยแค่ไหน |
| ผู้ดูแลระบบ: จัดการผู้ใช้ (Admin) | อนุมัติคำขอสมัคร เปิด/ปิดสิทธิ์ของทุกคน เปิดข้อนี้แล้วจะได้ทุกสิทธิ์อัตโนมัติ |

- ผู้ใช้ใหม่ (สมัครเอง หรือ admin เพิ่มให้) เริ่มต้นปิดทุกสิทธิ์ เข้าสู่ระบบได้แต่จะเห็นเฉพาะหน้า **My account** พร้อมข้อความให้ติดต่อผู้ดูแลระบบ
- บางสิทธิ์ต้องมีอีกข้อด้วย ระบบเปิดให้อัตโนมัติ: เพิ่ม/แก้ไขเพลง ลบเพลง และสร้างชุดเพลง ต้องมี "ดูเพลง" · ลบประวัติชุดเพลง ต้องมี "ดูประวัติ"
- ผู้ใช้เดิมก่อนอัปเดตนี้ยังใช้งานได้เหมือนเดิมตามบทบาทเดิม (Viewer = ดูเพลง ดูประวัติ ดูสถิติ · Worship leader = สิทธิ์ของ Viewer + เพิ่ม/แก้ไขเพลง สร้างชุดเพลง · Admin = ทุกสิทธิ์) จนกว่า admin จะกด Manage แล้วบันทึกสิทธิ์ใหม่
- การเปลี่ยนสิทธิ์มีผลทันทีที่ผู้ใช้คนนั้นกดใช้งานครั้งถัดไป ไม่ต้องออกจากระบบ (เมนูจะอัปเดตเมื่อเปิดระบบใหม่)
- แก้สิทธิ์ของตัวเองไม่ได้ (กันการปิดสิทธิ์ admin ของตัวเองโดยไม่ตั้งใจ)
- ช่อง "Access" ในรายชื่อผู้ใช้จะแสดง Admin / Worship leader / Viewer ถ้าสิทธิ์ตรงกับชุดเดิม ถ้าไม่ตรงจะแสดง "Custom access" (กำหนดเอง) พร้อมจำนวนสิทธิ์ที่เปิด

"ชื่อที่แสดง" จะถูกใช้เป็นชื่อผู้นำเพลงในสถิติ

## หมวดหมู่เพลง (Categories)

ใช้แทนช่อง "แท็ก" แบบเดิม

- **สร้างหมวดหมู่:** เมนู **Categories** (หมวดหมู่) ในแถบซ้าย เห็นเฉพาะคนที่มีสิทธิ์ "จัดการหมวดหมู่" (admin มีสิทธิ์นี้อัตโนมัติ ผู้ใช้อื่นเริ่มต้นปิด เปิดให้ได้ที่ Users → Manage)
  - เพิ่มหมวดหมู่ พิมพ์ชื่อแล้วกด **Add** (ชื่อยาวไม่เกิน 40 ตัวอักษร ห้ามซ้ำ มีได้สูงสุด 100 หมวด)
  - **Rename** เปลี่ยนชื่อ เพลงที่อยู่ในหมวดนั้นเปลี่ยนตามทันที
  - **Delete** ลบหมวดหมู่ หมวดนั้นจะถูกเอาออกจากทุกเพลง แต่ตัวเพลงยังอยู่
- **ใส่หมวดหมู่ให้เพลง:** หน้าเพิ่ม/แก้ไขเพลง ติ๊กเลือกได้หลายหมวด (ทุกคนที่แก้ไขเพลงได้ทำได้ ไม่ต้องมีสิทธิ์จัดการหมวดหมู่)
- **กรองเพลง:** หน้า Songs มีปุ่มหมวดหมู่ใต้ช่องค้นหา กดเพื่อดูเฉพาะเพลงในหมวดนั้น (ตัวเลขคือจำนวนเพลง) และพิมพ์ชื่อหมวดหมู่ในช่องค้นหาได้ด้วย
- หมวดหมู่ของเพลงแสดงใต้ชื่อเพลงในรายการ และในหน้าเพลง
- แท็กเดิมที่เคยใส่ไว้ยังเก็บในชีต (คอลัมน์ `Tags`) ไม่หาย แต่ไม่แสดงและไม่ใช้ค้นหาแล้ว ถ้าต้องการให้เพลงเดิมอยู่ในหมวดหมู่ ให้สร้างหมวดหมู่แล้วติ๊กในหน้าแก้ไขเพลง
- เพลงที่นำเข้าจากไฟล์ยังไม่มีหมวดหมู่ ใส่ได้ภายหลังในหน้าแก้ไขเพลง

## วิธีพิมพ์เพลง (ไม่ต้องใส่วงเล็บแล้ว)

ระบบใส่วงเล็บ `[ ]` ให้เองตอนบันทึก และแสดงตัวอย่างทันทีขณะพิมพ์ การเปลี่ยนคีย์ใช้ได้เหมือนเดิม

- **เนื้อไทย**: พิมพ์คอร์ดไว้หน้าพยางค์ เช่น `Cร้องเพลง G/Bถวาย` หรือ `C ร้องเพลง G/B ถวาย` (เว้นวรรค 1 ช่องหลังคอร์ดได้)
- **เนื้ออังกฤษ**: พิมพ์คอร์ดไว้บรรทัดบนของเนื้อเพลง ให้ตรงกับตัวอักษรที่ต้องการ (ช่องพิมพ์ใช้ฟอนต์ความกว้างเท่ากัน จึงจัดตำแหน่งได้ตรง)
  ```
  G       D
  Amazing grace
  ```
- **บรรทัดดนตรี**: `Intro: C G/B F Gsus4` หรือ `Solo: Am7 Em7 F G x2`
- **หัวข้อท่อน**: `Chorus:` `Bridge:` `ท่อน A` (แสดงเป็นตัวหนา) · บรรทัดว่าง = แบ่งท่อน และเป็นจุดที่ระบบเลือกตัดคอลัมน์
- **วางเพลงจาก Word** ที่คอร์ดอยู่บรรทัดบน: วางลงช่องที่ว่างอยู่ ระบบจะจัดรูปแบบให้เอง หรือกด **Tidy up chords** แล้วตรวจตำแหน่งในตัวอย่าง (เนื้อไทยจะถูกย้ายคอร์ดมาไว้หน้าพยางค์ แก้ตำแหน่งได้ง่าย)
- แบบเดิม `[C]ร้อง[G/B]เพลง` ยังใช้ได้ เพลงเดิมทั้งหมดไม่ต้องแก้ไข เปิดแก้ไขแล้วบันทึกโดยไม่เปลี่ยนอะไร เนื้อเพลงในชีตจะเหมือนเดิมทุกตัวอักษร

## นำเข้าเพลงจากไฟล์ Word / PDF

1. หน้า **Songs** กดปุ่ม **Import** (นำเข้าไฟล์) หรือหน้า **Add song** กด **Import from file** แล้วเลือกไฟล์ `.docx` หรือ `.pdf` (เลือกหลายไฟล์พร้อมกันได้)
2. ระบบอ่านไฟล์ในเครื่องของผู้ใช้เอง ไม่อัปโหลดไฟล์ขึ้นระบบและไม่เก็บไฟล์ไว้ที่ใด
3. ระบบแยกเพลงให้เอง ทั้งไฟล์ที่มีหลายเพลงในหน้าเดียว (รวมถึงแบบ 2 คอลัมน์) และหน้าละเพลง โดยดูจากชื่อเพลง (ตัวใหญ่กว่า หรือตัวหนา หรือจัดกึ่งกลาง) ถ้าไฟล์ไม่มีชื่อเพลงเลย ระบบแยกเพลงจากช่องว่างหลายบรรทัดหรือการขึ้นหน้าใหม่
4. คอร์ดที่พิมพ์ไว้บรรทัดบนของเนื้อเพลง ระบบวัดตำแหน่งแล้ววางคอร์ดให้ตรงพยางค์ บรรทัดดนตรี `Intro: C G` บรรทัด `Key: G` / `คีย์ G` และชื่อเพลงแบบ `1. ชื่อเพลง (Key G)` ระบบแปลงให้เอง
5. หน้า **Import songs** (ตรวจสอบก่อนบันทึก) แสดงทุกเพลงที่พบ แก้ได้ทุกอย่างก่อนบันทึก:
   - ช่องติ๊กหน้าเพลง = บันทึกเพลงนี้หรือไม่ (เพลงที่มีชื่อซ้ำกับเพลงในคลัง และเพลงที่ไม่พบคอร์ด จะไม่ได้ติ๊กไว้ให้)
   - ชื่อเพลง (ต้องใส่ถ้าไฟล์ไม่มีชื่อเพลง) และคีย์
   - ช่องเนื้อเพลงและคอร์ด พร้อมตัวอย่างทางขวา (บนมือถือกด Show preview)
   - **Split at cursor**: คลิกที่บรรทัดแรกของเพลงถัดไปแล้วกด เพื่อแยกเป็น 2 เพลง (ถ้าบรรทัดแรกเป็นชื่อเพลง ระบบใส่ให้เป็นชื่อเพลงใหม่)
   - **Join with previous**: รวมกับเพลงก่อนหน้า (กรณีระบบแยกเพลงยาวออกเป็น 2 ส่วน)
   - **Remove**: เอาเพลงนั้นออกจากรายการ
6. กด **Save N songs** ระบบบันทึกเพลงที่ติ๊กไว้ทั้งหมดในครั้งเดียว แล้วกลับไปหน้า Songs
7. ถ้าปิดหน้าไปก่อนบันทึก รายการที่กำลังตรวจสอบยังอยู่ในเครื่องนั้น หน้า Songs จะมีปุ่ม **Continue review** ให้ทำต่อ (กด **Discard all** ถ้าไม่ต้องการ)

ข้อจำกัด:
- รองรับเฉพาะ `.docx` และ `.pdf` ไฟล์ Word แบบเก่า (`.doc`) ให้เปิดใน Word แล้ว Save As เป็น `.docx` ก่อน
- PDF ที่สแกนเป็นรูปภาพ อ่านไม่ได้ (ไม่มีข้อความในไฟล์)
- PDF บางไฟล์ (เช่นที่สั่งพิมพ์จาก Chrome) ไม่ได้เก็บข้อมูลวรรณยุกต์/สระบนที่ซ้อนกันไว้ ระบบจะติดป้าย **Check the Thai spelling** ให้ตรวจตัวสะกดก่อนบันทึก ไฟล์ Word อ่านได้ครบ
- ไฟล์ PDF ใช้ตัวอ่าน pdf.js ที่โหลดจากอินเทอร์เน็ต (cdnjs) ครั้งแรกที่นำเข้า PDF ต้องต่ออินเทอร์เน็ต

## การเปลี่ยนคีย์

- กด **+ ½** / **− ½** เพื่อเลื่อนทีละครึ่งเสียง ระบบเปลี่ยนทุกคอร์ดในเพลงให้เอง และไฟล์ PDF/Word จะใช้คอร์ดชุดเดียวกับที่เห็นบนจอ
- โหมด **#/b auto** (ค่าเริ่มต้น) ใช้ชื่อโน้ตชุดนี้เสมอ: `C C# D Eb E F F# G G# A Bb B`
- ที่คีย์เดิม (เลื่อน 0) ระบบแสดงคอร์ดตามที่พิมพ์ไว้ในเพลง
- ถ้าต้องการชื่อแบบชาร์ปทั้งหมดหรือแฟลตทั้งหมด เลือก **Use #** หรือ **Use b** ได้

## ใช้งานบนมือถือ

- เปิดลิงก์ https://waranchit-source.github.io/chordsheet/ บนมือถือได้เลย หน้าจอปรับตามขนาดเครื่อง เมนูอยู่ในแถบด้านซ้าย กดปุ่มแถบเมนูที่มุมซ้ายบนเพื่อเปิด
- หน้าเพลงบนมือถือ: ปุ่ม − ½ / + ½ / คีย์เดิม / ขนาดตัวอักษร ติดอยู่ด้านล่างจอตลอด เลื่อนอ่านเพลงไปพร้อมกับเปลี่ยนคีย์ได้
- เพิ่มเป็นไอคอนบนหน้าจอหลัก (เปิดเต็มจอเหมือนแอป):
  - **iPhone / iPad (Safari)**: กดปุ่มแชร์ → **Add to Home Screen** (เพิ่มไปยังหน้าจอโฮม)
  - **Android (Chrome)**: กดเมนู ⋮ → **Add to Home screen** หรือ **Install app**
- บน iPhone แอปที่เพิ่มไว้ที่หน้าจอหลักจะจำการเข้าสู่ระบบแยกจาก Safari ให้เข้าสู่ระบบในแอปครั้งแรกและติ๊ก Remember me

## แถบเมนูด้านซ้าย (Sidebar)

- เมนูทั้งหมด (เพลง ชุดเพลง ประวัติ สถิติ ผู้ใช้ บัญชี) ปุ่มเปลี่ยนภาษา ปุ่มธีม และปุ่มออกจากระบบ อยู่ในแถบด้านซ้าย
- ปุ่มปิดแถบเมนูอยู่ในแถบเมนู มุมขวาบนข้างชื่อระบบ เมื่อปิดแล้ว ปุ่มเปิดจะอยู่มุมซ้ายบนข้างชื่อหน้าที่เปิดอยู่
- คอมพิวเตอร์ (จอกว้าง 1024px ขึ้นไป): แถบเมนูเปิดค้างไว้ข้างเนื้อหา ถ้าปิดไว้ ระบบจะจำไว้ครั้งต่อไป
- มือถือและแท็บเล็ต: แถบเมนูเลื่อนออกมาทับหน้าจอ ปิดได้ด้วยปุ่ม X ในแถบเมนู แตะพื้นที่ด้านนอก หรือเลือกเมนู
- แถบเมนูแสดงเฉพาะหน้าที่ผู้ใช้มีสิทธิ์

## ความเร็ว

- เข้าสู่ระบบครั้งเดียวได้ข้อมูลเพลงทั้งหมดในคำขอเดียว (เดิมต้องเรียกเซิร์ฟเวอร์ 4 ครั้ง)
- เปิดเพลงและเพิ่มเพลงลงชุดได้ทันที ไม่ต้องรอเซิร์ฟเวอร์
- เปิดระบบครั้งถัดไป รายการเพลงแสดงทันทีจากข้อมูลที่จำไว้ในเครื่อง แล้วอัปเดตจากเซิร์ฟเวอร์ให้เองเบื้องหลัง
- หน้าประวัติและสถิติแสดงข้อมูลล่าสุดที่เคยโหลดทันที แล้วอัปเดตเบื้องหลัง
- การสร้างไฟล์ PDF/Word ยังใช้เวลาตามความเร็วของ Google (ประมาณ 10 ถึง 30 วินาที)

## ภาษาและธีม

- ภาษาเริ่มต้นเป็นภาษาอังกฤษ กดปุ่ม **ไทย** ที่มุมขวาบน (หรือในเมนูบนมือถือ) เพื่อเปลี่ยนเป็นภาษาไทย กด **English** เพื่อกลับ ระบบจำภาษาที่เลือกไว้
- ปุ่มพระจันทร์/พระอาทิตย์ สลับธีมมืด/สว่าง (ค่าเริ่มต้นตามเครื่อง)

## การจัดหน้ากระดาษ

- **อัตโนมัติ**: ถ้าเพลงพอดีครึ่งหน้า จะวาง 2 เพลงต่อหน้า (ซ้าย/ขวา) ถ้าเพลงยาวเกินครึ่งหน้า จะใช้ทั้งหน้าโดยแบ่งเป็น 2 คอลัมน์ ถ้ามีบรรทัดยาวเกินครึ่งหน้า จะใช้ทั้งหน้าแบบคอลัมน์เดียว
- **ครึ่งหน้า / เต็มหน้า**: บังคับเองได้ทั้งตอนตั้งค่าเพลง และในแต่ละชุดเพลง
- หลังสร้างไฟล์ ระบบจะแสดงว่าแต่ละหน้ามีเพลงอะไรบ้าง

## PDF / Word (ดาวน์โหลดลงเครื่อง)

- กด **Create and download file** (สร้างและดาวน์โหลดไฟล์) ไฟล์จะดาวน์โหลดลงเครื่องของคนที่กดทันที ดูได้ในโฟลเดอร์ดาวน์โหลด (Downloads) ของเครื่องนั้น
- ระบบ **ไม่เก็บไฟล์ใน Google Drive แล้ว** ระหว่างสร้างไฟล์ ระบบสร้าง Google Doc ชั่วคราว แปลงเป็นไฟล์ แล้วลบทิ้งถาวรทันที (ไม่อยู่ในถังขยะ) ประวัติเก็บเฉพาะรายชื่อเพลงและคีย์ที่ผู้นำเลือก
- ไม่มีคำอธิบาย → ได้ **PDF** (พร้อมพิมพ์)
- มีคำอธิบาย (ของชุดหรือของเพลงใดเพลงหนึ่ง) หรือเลือก Word เอง → ได้ไฟล์ **Word (.docx)** แก้ไขได้ใน Microsoft Word หรืออัปโหลดเข้า Google Docs ของตัวเอง
- ตำแหน่งคอร์ดใน PDF: ระบบใช้ตัวแปลงตัวเดียวกับเมนู File → Download → PDF ของ Google Docs คอร์ดจึงตรงพยางค์เหมือนเปิดใน Docs (ถ้าตัวแปลงนี้ขัดข้องชั่วคราว ระบบจะใช้วิธีสำรองเดิมให้เอง)
- หลังสร้างไฟล์ มีปุ่ม **Download again** (ดาวน์โหลดอีกครั้ง) ถ้าเผลอปิดหน้าดาวน์โหลด
- สร้างไฟล์ซ้ำในชุดเดิม (เช่น ทำ PDF แล้วทำ Word อีกไฟล์ หรือแก้คีย์แล้วสร้างใหม่) ระบบจะอัปเดตรายการเดิมในประวัติ ไม่เพิ่มรายการซ้ำ
- เมื่อชุดเพลงเรียบร้อยแล้ว กด **Finish setlist** (ปิดงาน) หน้าชุดเพลงจะถูกล้างให้พร้อมทำชุดใหม่ และพาไปหน้าประวัติ รายชื่อเพลงของชุดนั้นยังอยู่ในประวัติ
- ไฟล์เก่าในโฟลเดอร์ `Chord Sheet Files` ใน Google Drive ระบบไม่ใช้แล้ว ลบเองได้ตามต้องการ
- ถ้าเปิดไฟล์ .docx ใน Microsoft Word ควรติดตั้งฟอนต์ Sarabun (ฟรีจาก Google Fonts) ไว้ในเครื่อง ไม่อย่างนั้นตำแหน่งคอร์ดจะเลื่อนเล็กน้อย

## ประวัติชุดเพลง (History)

- แต่ละชุดแสดงเป็นการ์ด: วันที่ ชื่อชุด ผู้นำเพลง จำนวนเพลง และรายชื่อเพลงเรียงตามลำดับ พร้อมคีย์ที่ใช้
- ค้นหาได้จากชื่อชุด ผู้นำเพลง ชื่อเพลง หรือวันที่
- ปุ่ม **Use again** (ใช้ชุดนี้อีกครั้ง) โหลดชุดนั้นกลับมาที่หน้าชุดเพลง (ต้องมีสิทธิ์สร้างชุดเพลง)
- ปุ่ม **Delete** ลบชุดนั้นพร้อมสถิติของชุด (ต้องมีสิทธิ์ลบประวัติชุดเพลง)

## ข้อมูลในชีต

- `Songs` คลังเพลงทั้งหมด (ลบแล้วจะติดค่า Deleted = TRUE ไม่ได้ลบแถวจริง) คอลัมน์ `Categories` เก็บรหัสหมวดหมู่ของเพลง
- `Categories` รายชื่อหมวดหมู่ (ชีตนี้ระบบสร้างให้เองตอนใช้งานครั้งแรกหลัง Deploy)
- `Setlists` ประวัติชุดเพลงทุกชุด: วันที่ ผู้นำเพลง รายการเพลง/คีย์ที่ใช้ (คอลัมน์ `DocId`, `PdfId` ว่างสำหรับชุดใหม่ เพราะไม่เก็บไฟล์แล้ว)
- `UsageLog` บันทึกการใช้เพลงทีละเพลง ใช้คำนวณสถิติ
- `Users` ผู้ใช้ (รหัสผ่านเก็บแบบ hash) คอลัมน์ `Status` = `pending` / `approved` / `rejected` (ช่องว่าง = approved สำหรับผู้ใช้เดิม) คอลัมน์ `Permissions` = รายการสิทธิ์ที่เปิด (ช่องว่าง = ใช้สิทธิ์ตามบทบาทเดิมในคอลัมน์ `Role`)
- `Sessions` การจดจำการเข้าสู่ระบบ (เก็บเฉพาะ hash ของ token และวันหมดอายุ)

ไม่ควรแก้หัวคอลัมน์ในแถวแรกของทุกชีต
