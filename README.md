# ระบบเนื้อเพลงและคอร์ด (Google Apps Script)

## ไฟล์ในโปรเจกต์

| ไฟล์ใน Apps Script | ประเภท | หน้าที่ |
|---|---|---|
| Code.gs | Script | เปิดหน้าเว็บ (doGet) |
| Config.gs | Script | ค่าตั้งต้น ชื่อชีต ขนาดฟอนต์ ระยะขอบกระดาษ |
| Setup.gs | Script | สร้างชีต โฟลเดอร์ Drive และผู้ใช้ admin |
| Db.gs | Script | อ่าน/เขียน Google Sheets |
| Auth.gs | Script | ล็อกอิน สิทธิ์ผู้ใช้ จัดการผู้ใช้ |
| Songs.gs | Script | เพิ่ม/แก้ไข/ลบเพลง |
| Setlists.gs | Script | สร้างชุดเพลง ไฟล์ Doc/PDF ประวัติ |
| Stats.gs | Script | สถิติการใช้เพลง |
| Render.gs | Script | จัดหน้า A4 2 เพลง/หน้า วางคอร์ดเหนือพยางค์ |
| FontMetrics.gs | Script | ตารางความกว้างตัวอักษรฟอนต์ Sarabun |
| Index.html | HTML | หน้าเว็บหลัก |
| Styles.html | HTML | CSS |
| Chords.html | HTML | ระบบเปลี่ยนคีย์และแสดงคอร์ด |
| App.html | HTML | หน้าจอทั้งหมดของระบบ |
| appsscript.json | Manifest | ตั้งค่าโปรเจกต์ |

## ติดตั้ง

1. สร้าง Google Sheet ใหม่ ตั้งชื่อตามต้องการ เช่น "ระบบเนื้อเพลงและคอร์ด - Database"
2. ในชีตไปที่ **Extensions → Apps Script**
3. ลบโค้ดใน `Code.gs` เดิมทิ้ง แล้ววางเนื้อหาจากไฟล์ `Code.gs`
4. สร้างไฟล์ Script ที่เหลือ: กด **+** ข้าง Files → **Script** → ตั้งชื่อตามตาราง (ไม่ต้องพิมพ์ .gs) แล้ววางโค้ด
5. สร้างไฟล์ HTML: กด **+** → **HTML** → ตั้งชื่อ `Index`, `Styles`, `Chords`, `App` (ไม่ต้องพิมพ์ .html) แล้ววางโค้ด
6. เปิดไฟล์ `appsscript.json`: ไปที่ **Project Settings (ไอคอนเฟือง)** → ติ๊ก **Show "appsscript.json" manifest file in editor** → กลับมาที่ Editor เปิด `appsscript.json` แล้ววางทับทั้งไฟล์
7. กด **Save project** (Ctrl+S)

## รัน setup ครั้งแรก

1. เลือกไฟล์ `Setup.gs` → เลือกฟังก์ชัน `setup` ในแถบด้านบน → กด **Run**
2. กด **Review permissions** → เลือกบัญชี Google → **Advanced** → **Go to (ชื่อโปรเจกต์) (unsafe)** → **Allow**
3. เปิด **Execution log** ด้านล่าง จะเห็น
   - Username: `admin` และ Password ที่ระบบสุ่มให้ (จดไว้)
   - ลิงก์โฟลเดอร์ใน Drive: `Chord Sheet Files` ที่มีโฟลเดอร์ย่อย `Docs` และ `PDF`
4. ในชีตจะมีแท็บ `Users`, `Songs`, `Setlists`, `UsageLog` เกิดขึ้น

ถ้าลืมรหัส admin: เลือกฟังก์ชัน `resetAdminPassword` → Run → ดูรหัสใหม่ใน Execution log

## Deploy เป็นเว็บแอป (ครั้งแรก)

1. กด **Deploy → New deployment**
2. กดไอคอนเฟืองข้าง "Select type" → เลือก **Web app**
3. Description: เช่น `v1`
4. Execute as: **Me**
5. Who has access: **Anyone**
6. กด **Deploy** → คัดลอก **Web app URL** (ลงท้ายด้วย `/exec`) ไปแจกผู้ใช้

## อัปเดตโค้ดหลังแก้ไข (ทุกครั้ง)

1. แก้โค้ดแล้วกด **Save project**
2. กด **Deploy → Manage deployments**
3. เลือก deployment เดิม → กดไอคอน **ดินสอ (Edit)**
4. ช่อง Version เลือก **New version**
5. กด **Deploy**

URL เดิมจะใช้ได้ต่อ ไม่ต้องแจกลิงก์ใหม่

## สิทธิ์ผู้ใช้

| สิทธิ์ | ทำอะไรได้ |
|---|---|
| ดูอย่างเดียว (viewer) | ดูเพลง เปลี่ยนคีย์บนจอ ดูประวัติ ดาวน์โหลดไฟล์ ดูสถิติ |
| ผู้นำเพลง (leader) | ทุกอย่างของ viewer + เพิ่ม/แก้ไขเพลง สร้างชุดเพลง สร้างไฟล์ |
| ผู้ดูแลระบบ (admin) | ทุกอย่าง + ลบเพลง ลบชุดเพลง จัดการผู้ใช้ |

เพิ่มผู้ใช้ได้ที่เมนู **ผู้ใช้** ช่อง "ชื่อที่แสดง" จะถูกใช้เป็นชื่อผู้นำเพลงในสถิติ

## วิธีพิมพ์เพลง

- วางคอร์ดในวงเล็บเหลี่ยมหน้าพยางค์: `[C]ร้อง[G/B]เพลง[Am7]ถวาย`
- บรรทัดดนตรี: `Intro: [C] [G/B] [F] [Gsus4]` หรือ `Solo: [Am7 Em7 F G] x2`
- หัวข้อท่อน: `Chorus:` `Bridge:` (แสดงเป็นตัวหนา)
- บรรทัดว่าง = แบ่งท่อน และเป็นจุดที่ระบบเลือกตัดคอลัมน์เมื่อเพลงยาว
- ถ้าวางเพลงจาก Word ที่คอร์ดอยู่บรรทัดบน ให้กดปุ่ม **แปลงจากแบบคอร์ดอยู่บรรทัดบน** แล้วตรวจในช่องตัวอย่าง

## การจัดหน้ากระดาษ

- **อัตโนมัติ**: ถ้าเพลงพอดีครึ่งหน้า จะวาง 2 เพลงต่อหน้า (ซ้าย/ขวา) ถ้าเพลงยาวเกินครึ่งหน้า จะใช้ทั้งหน้าโดยแบ่งเป็น 2 คอลัมน์ ถ้ามีบรรทัดยาวเกินครึ่งหน้า จะใช้ทั้งหน้าแบบคอลัมน์เดียว
- **ครึ่งหน้า / เต็มหน้า**: บังคับเองได้ทั้งตอนตั้งค่าเพลง และในแต่ละชุดเพลง
- หลังสร้างไฟล์ ระบบจะแสดงว่าแต่ละหน้ามีเพลงอะไรบ้าง

## PDF / Word

- ไม่มีคำอธิบาย → ได้ **PDF** เก็บในโฟลเดอร์ `Chord Sheet Files/PDF`
- มีคำอธิบาย (ของชุดหรือของเพลงใดเพลงหนึ่ง) หรือเลือก Word เอง → ได้ **Google Doc** เก็บใน `Chord Sheet Files/Docs` เปิดแก้ใน Google Docs หรือดาวน์โหลดเป็น .docx ได้
- แก้ Doc เสร็จแล้ว กด **แก้ไขเสร็จแล้ว → สร้าง PDF** หรือกด **สร้าง PDF จาก Doc** ในหน้าประวัติ ไฟล์ PDF จะไปอยู่ในโฟลเดอร์ PDF
- ไฟล์ตั้งค่าให้ "ทุกคนที่มีลิงก์" เปิดได้ (PDF = ดูอย่างเดียว, Doc = แก้ไขได้) เพื่อให้ผู้ใช้ที่ล็อกอินด้วย username ของระบบเปิดไฟล์ได้
- ถ้าเปิดไฟล์ .docx ใน Microsoft Word ควรติดตั้งฟอนต์ Sarabun (ฟรีจาก Google Fonts) ไว้ในเครื่อง ไม่อย่างนั้นตำแหน่งคอร์ดจะเลื่อนเล็กน้อย

## ปรับแต่ง (Config.gs)

| ค่า | ความหมาย |
|---|---|
| `LYRIC_SIZE`, `CHORD_SIZE` | ขนาดตัวอักษรเนื้อเพลง/คอร์ด (pt) |
| `TITLE_SIZE`, `HEADER_SIZE` | ขนาดชื่อเพลง/หัวกระดาษ |
| `MARGIN_*` | ระยะขอบกระดาษ (pt, 28.35 pt = 1 ซม.) |
| `LINE_HEIGHT_EM` | ค่าประมาณความสูงบรรทัด ถ้าเพลงล้นหน้าให้เพิ่ม ถ้าระบบตัดเป็นเต็มหน้าบ่อยเกินไปให้ลด |
| `CHORD_COLOR` | สีคอร์ด |
| `DRIVE_FOLDER_NAMES` | ชื่อโฟลเดอร์ใน Drive (ต้องแก้ก่อนรัน setup) |

## ข้อมูลในชีต

- `Songs` คลังเพลงทั้งหมด (ลบแล้วจะติดค่า Deleted = TRUE ไม่ได้ลบแถวจริง)
- `Setlists` ประวัติชุดเพลงทุกชุด พร้อมไฟล์และรายการเพลง/คีย์ที่ใช้
- `UsageLog` บันทึกการใช้เพลงทีละเพลง ใช้คำนวณสถิติ
- `Users` ผู้ใช้ (รหัสผ่านเก็บแบบ hash)

ไม่ควรแก้หัวคอลัมน์ในแถวแรกของทุกชีต
